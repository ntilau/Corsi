# Abilitazione — Esame di Stato, Ingegneria dell'Informazione

Materiale di preparazione all'esame di abilitazione all'esercizio della professione di Ingegnere dell'Informazione, proveniente dai corsi dell'università di Prato.

## Contenuti

| Directory | Descrizione |
|-----------|-------------|
| `abilitazione.pdf` | Documento principale di sintesi dell'esame di abilitazione |
| `documenti/` | Documenti amministrativi — calendario prove, domande, esiti sessioni 2010 |
| `vecchi_compiti/` | Temi d'esame passati (elettronica, ingegneria dell'informazione, telecomunicazioni) |

## Struttura dell'esame

L'esame di abilitazione si compone di:
1. **Prova scritta** — temi d'esame su elettronica, sistemi, telecomunicazioni, campi
2. **Prova orale** — discussione su discipline dell'indirizzo informazione
3. **Prova pratica** — progetto o relazione tecnica

I `vecchi_compiti/` coprono la prova scritta.

## Lingua

Il materiale è interamente in italiano, lingua ufficiale dell'esame.

## Origine

Materiale proveniente dall'università di Prato (indirizzo Ingegneria dell'Informazione).
